--------------------------------------------------------------------------------
PART 1: THE QUICK OVERVIEW (WHAT IS IT IN SUPER SIMPLE WORDS?)
--------------------------------------------------------------------------------
RookieStuff is an automated AI junior developer.
Whenever someone opens a Pull Request (PR) on GitHub:
1. It pulls the code.
2. It tests and lints the code in a safe sandbox folder (checks spacing, syntax, and bugs).
3. It rewrites the code to be clean, pretty, and bug-free using an LLM.
4. It STOPS before committing and calls you (Human-in-the-Loop).
5. If you say "Fix this with list comprehensions", it rewinds, rewrites, and asks again.
6. When you click "Approve", it pushes the clean code to GitHub automatically.

--------------------------------------------------------------------------------
PART 2: WHAT I HAVE USED (THE TECH STACK IN 5 BULLETS)
--------------------------------------------------------------------------------
1. Python 3.11: The programming language running everything.
2. LangGraph: The "brain". Unlike simple AI chains that forget everything, LangGraph 
   is a state machine. It remembers the whole conversation, can loop backward if you 
   reject a draft, and pauses whenever you need human approval.
3. Flake8 & Black: The quality inspectors. Flake8 finds bugs and styling flaws; 
   Black cleans up indentation and formatting.
4. FastAPI: The web server. It receives webhooks from GitHub and serves our web 
   dashboard on http://localhost:3000.
5. Docker & Pytest: Containerization to run anywhere, plus 16 automated tests to 
   prove everything works.

--------------------------------------------------------------------------------
PART 3: WHAT IT DOES (THE 4 CORE STEPS)
--------------------------------------------------------------------------------
- Step 1: fetch_pr_node -> Pulls code from GitHub PR.
- Step 2: lint_code_node -> Runs Flake8 and Black in a safe temporary folder.
- Step 3: propose_refactor_node -> LLM generates clean code fixing the errors.
- Step 4: apply_changes_node -> Paused by interrupt_before. Commits only when approved.
